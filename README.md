# 蘑菇戰情室

家人共用的皮克敏蘑菇重生倒數看板。打開網頁就能看到每個點位還剩多久重生，多人同時使用會即時同步。

## 功能

- **17 個點位倒數**：分四欄排列
- **自動加 5 分鐘緩衝**：輸入遊戲內剩餘時間後，倒數會自動多算 5 分鐘，避免提早跑一趟
- **即時同步**：任何人設定倒數，其他人的畫面約 1 秒內同步更新
- **免登入**：直接開網址就能用，不用帳號密碼
- **狀態一眼分辨**：倒數中為白字，剩 5 分鐘內轉為警示色，時間到顯示「🍄 已重生！」

## 怎麼用

1. 開啟網址（家人之間私下分享，勿公開張貼）。
2. 找到對應的蘑菇點位卡片。
3. 在「時 / 分 / 秒」欄位填入遊戲裡看到的剩餘時間。
4. 按「開始倒數！」——所有人的畫面同步更新。

## 技術架構

純靜態網頁，無後端伺服器：

- 前端：原生 HTML / CSS / JavaScript，部署於 **GitHub Pages**
- 資料同步：**Supabase**（PostgreSQL + Realtime），免費方案
- 部署：推送 `main` 後由 GitHub Actions 自動發佈

```
index.html          # 頁面與樣式
js/app.js           # 倒數邏輯 + Supabase 同步（點位清單在這裡）
supabase/schema.sql # 資料表與權限設定
.github/workflows/  # Pages 自動部署
```
